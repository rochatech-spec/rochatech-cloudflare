# Ritmo Finance

Projeto novo criado exclusivamente a partir do ZIP `Ritmo-HTML5-CSS3.zip` e da arquitetura Rocha Tech informada nesta conversa.

## Stack
React + TypeScript + Vite + PWA + Cloudflare Pages Functions/Worker + D1 + R2 + WebAuthn + IndexedDB/outbox.

## Produção
O workflow `ritmo-finance-production.yml` provisiona D1/R2, aplica o schema, compila, publica e valida o PWA em `https://ritmo-finance-br.pages.dev`.
