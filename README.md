# RochaTech Cloudflare

Plugin moderno para administrar a Cloudflare pela API MCP oficial, usando OAuth e integração com GitHub.

## Recursos

- Cloudflare API completa por `search` e `execute`
- OAuth oficial, sem tokens gravados no código
- Pages, Workers, D1, R2, KV, domínios e builds
- Diagnóstico com Workers Builds e Observability
- Auditoria de alterações com Audit Logs
- Assistência especializada para bindings e documentação atualizada
- Padrão RochaTech com GitHub como fonte e Cloudflare como infraestrutura de build e deploy
- Proteções para operações destrutivas e prevenção de custos inesperados

## Autenticação

Na primeira utilização, a Cloudflare abre a autorização OAuth. Escolha a conta correta e conceda somente as permissões necessárias. A sessão é gerenciada pela Cloudflare e pode ser revogada nas configurações da conta.
